1. 程序简介

DSurfTomo-LST 是在 DSurfTomo 三维面波频散直接反演程序基础上发展的自适应字典正则化层析成像程序。程序直接利用台站对之间的面波频散数据反演三维横波速度结构，不需要先构建不同周期的二维相速度或群速度图。

程序保留了 DSurfTomo 的快速行进法（Fast Marching Method, FMM）正演、射线路径更新和三维灵敏度矩阵计算。在此基础上加入局部稀疏正则化：反演初期采用 Laplacian 正则化建立大尺度速度背景，随后切换到基于局部 patch 的字典正则化。各反演深度层使用独立字典，并通过深度方向耦合约束相邻层之间的连续性。

局部模型采用 OMP（Orthogonal Matching Pursuit）进行稀疏编码，字典采用 ITKM（Iterative Thresholding and signed K-Means）更新。

3. 运行程序

3.1 使用 Run.bat

双击 Run.bat 启动程序。脚本内容如下：

@echo off
cd /d "%~dp0"

DSurfTomo_lst.exe DSurfTomo_lst.in

echo.
echo Calculation finished.
pause

cd /d "%~dp0" 将工作目录和盘符切换到 Run.bat 所在目录，使程序能够按相对路径读取同目录中的参数文件、模型和数据文件。

3.2 命令行运行

在 Windows CMD 或 PowerShell 中进入程序目录后运行：

DSurfTomo_lst.exe DSurfTomo_lst.in

程序正常结束时会显示： 

Program finishes successfully

Run.bat 中的 pause 会在程序结束后保留窗口，按任意键即可关闭。

4. 面波频散数据

频散数据文件由 DSurfTomo_lst.in 第一项指定。示例文件名为： 

surfdataTB.dat

数据格式沿用 DSurfTomo。例如：

# 25.148500 121.511100 1 2 0
25.158529 121.476890 0.7990
25.133539 121.499190 1.0420

# 25.158529 121.476890 1 2 0
25.119850 121.473190 0.6460

每组数据以一行源台站信息开始：

# source_lat source_lon period_index wave_type velocity_type
字段说明
source_lat源台站纬度。
source_lon源台站经度。
period_index周期编号，从 1 开始，对应参数文件中该类频散数据的周期顺序。
wave_type2：Rayleigh 波；1：Love 波。
velocity_type0：相速度；1：群速度。

随后列出与该源台站配对的接收台站：

receiver_lat receiver_lon velocity

其中 receiver_lat 和 receiver_lon 为接收台站纬度和经度，velocity 为该台站对在相应周期上的相速度或群速度。这里的“源台站”和“接收台站”表示程序中一个台站对的两个角色。

例如，某类频散数据的周期依次为 0.5 0.6 0.7 ... s，则 period_index=1 对应 0.5 s，period_index=2 对应 0.6 s，依此类推。

若同时使用多种频散数据，数据块按 Rayleigh 波相速度、Rayleigh 波群速度、Love 波相速度、Love 波群速度的顺序组织。

合成测试同样需要频散数据文件。 程序从该文件读取台站分布、台站对信息、周期和数据类型，再利用 MOD.true 计算合成数据。

5. 初始模型 MOD

程序从运行目录读取文件：

MOD

MOD 第一行给出深度节点，单位为 km。例如：

0.0 0.2 0.4 0.6 0.8 1.1 1.4 1.8 2.5

若 nz=9，第一行必须给出 9 个深度节点。

其余部分为三维横波速度。文件按深度层分组；每个深度层内按经度方向逐行排列，每行依次给出 nx 个纬度网格点的速度。因此纬度索引变化最快，其次为经度索引，最后为深度索引。

对于 nx=18、ny=18、nz=9 的示例：

  • 第一行包含 9 个深度节点；
  • 随后共有 ny × nz = 162 行速度数据；
  • 每行包含 nx = 18 个横波速度值。

模型速度单位为 km/s。

6. 合成真实模型 MOD.true

当参数文件中设置：

synthetic flag = 1

程序读取 MOD.true 作为合成测试的真实速度模型。

MOD.true 不包含深度节点行，只包含三维速度值；深度节点仍由 MOD 第一行提供。速度排列顺序与 MOD 中的三维速度部分相同。

对于 18 × 18 × 9 的模型，MOD.true 包含 162 行速度数据，每行 18 个值。

当 synthetic flag = 0 时，程序不读取 MOD.true。

7.1 基本反演参数

示例值参数说明
surfdataTB.dat data file 频散数据文件名。
18 18 9 nx ny nz 纬度、经度和深度方向的模型网格节点数。
25.2 121.35 goxd gozd 模型参考位置的纬度和经度。纬度方向随网格索引增大而减小，经度方向随网格索引增大而增大。
0.015 0.017 dvxd dvzd 纬度和经度方向的网格间距，单位为度。
20 max sources/receivers 源台站数以及每个源台站对应接收台站数的数组上限。该值应不小于数据中的实际数量。
4.0 1.0 weight damp weight 为正则化权重尺度；damp 为 warm-up 阶段传入 LSMR 的阻尼参数。
3 sublayers 计算深度灵敏度核时每个模型层采用的子层数。
0.5 2.8 Minvel Maxvel 模型允许的最小和最大横波速度，单位为 km/s。
10 maximum iteration 最大外循环次数。
0.2 sparsity fraction 用于预分配稀疏灵敏度矩阵存储空间的参数，与字典稀疏度 T_sparse 无关。
26 kmaxRc Rayleigh 波相速度的周期数；下一行给出对应周期。
0.5 ... 3.0 periods Rayleigh 波相速度周期，单位为 s。
0 kmaxRg Rayleigh 波群速度的周期数。
0 kmaxLc Love 波相速度的周期数。
0 kmaxLg Love 波群速度的周期数。
1 synthetic flag 0：实际数据反演；1：合成测试。
0.02 noiselevel 合成测试使用的噪声参数，仅在 synthetic flag=1 时生效。
2.0 threshold 残差异常值筛选参数。

当 kmaxRg、kmaxLc 或 kmaxLg 大于 0 时，其下一行应给出相同数量的周期值；当周期数为 0 时，不需要对应的周期行。

goxd 和 gozd 控制模型的水平位置。程序输出的反演区域纬度范围为 goxd-(nx-3)×dvxd 至 goxd，经度范围为 gozd 至 gozd+(ny-3)×dvzd。

warm-up 阶段使用输入的 damp。进入字典正则化阶段后，LSMR 的 damp 设为 0，字典约束由附加的正则化方程给出。

每次模型更新后，速度限制在 Minvel 和 Maxvel 范围内；单次速度扰动的绝对值最多为 0.5 km/s。

threshold 用于残差筛选。每次外循环计算残差的第 25 和第 75 百分位数 q25、q75，不在 [q25×threshold, q75×threshold] 范围内的数据在该次迭代中的权重设为 0。

7.2 参数文件格式

参数文件开头的前三行是说明行，程序读取后直接跳过，因此这三行应保留。基本反演参数按固定顺序读取。

LST 参数部分允许出现空行，也允许使用以 c、C、! 或 # 开头的独立注释行。参数值后也可以保留说明文字。

8. LST 字典参数

示例取值：

lam1_dict    = 1.0
lam2_dict    = 16.0
lam_z_dict   = 0.5
nib          = 4
K_dict       = 16
T_sparse     = 2
warmup_iters = 5
itkm_maxit   = 50
perc_thresh  = 0.10
dict_freq    = 3
参数示例值说明
lam1_dict 1.0 控制字典辅助模型对全局模型更新的约束强度。
lam2_dict 16.0 控制全局模型与重叠 patch 重构结果在辅助模型中的相对权重。
lam_z_dict 0.5 深度方向相邻层的耦合参数；0 表示各层独立。
nib 4 二维 patch 的边长，以网格节点数计。示例中 patch 为 4×4。
K_dict 16 每个反演深度层的字典原子数。
T_sparse 2 稀疏度参数。OMP 最多选取该数量的原子，ITKM 也使用该稀疏度进行字典更新。
warmup_iters 5 切换到字典正则化之前采用 Laplacian 正则化的外循环次数。
itkm_maxit 50 每次字典更新时执行的 ITKM 内部迭代次数。
perc_thresh 0.10 字典训练时允许 patch 内零覆盖节点所占的最大比例。
dict_freq 3 字典更新的外循环间隔。

8.1 正则化参数

lam1_dict 与 weight 共同控制字典约束在全局反演中的强度。程序加入 LSMR 方程组的字典约束系数与 sqrt(lam1_dict) × weight 成正比。

lam2_dict 用于融合全局模型和局部 patch 重构结果。由于程序采用步长为 1 的重叠 patch 并使用周期边界，每个水平网格节点由 nib² 个 patch 覆盖。当 lam_z_dict=0 且 lam2_dict=nib² 时，全局模型与所有 patch 重构结果的总权重处于相同尺度。示例中 nib=4，因此 nib²=16，并取 lam2_dict=16。

lam_z_dict 控制相邻深度层之间的联系。取 0 时各层独立；取正值时启用深度方向耦合。

8.2 patch、字典和稀疏度

nib 决定局部 patch 尺寸，K_dict 决定每层字典包含的原子数，T_sparse 决定每个 patch 使用的稀疏表示复杂度。示例中 nib=4、K_dict=16、T_sparse=2。

patch 在水平模型上以步长 1 提取，并在模型边界采用 wrap-around（周期边界）处理。

8.3 warm-up 与字典更新

warmup_iters=5 时，第 1–5 次外循环使用 Laplacian 正则化，第 6 次外循环开始使用字典正则化。程序在第 5 次外循环结束时建立并首次更新字典，为下一次迭代准备字典约束。

dict_freq=3 时，此后每隔 3 次外循环更新一次字典。itkm_maxit=50 表示每次更新执行 50 次 ITKM 内部迭代。

8.4 射线覆盖筛选

程序根据每个模型参数的 DWS 构造归一化覆盖信息，并统计每个 patch 中零覆盖节点的比例。当该比例大于 perc_thresh 时，该 patch 不参加本次 ITKM 字典训练。示例中的 perc_thresh=0.10 表示零覆盖节点超过 10% 的 patch 被排除。

9.1 实际数据反演

synthetic flag = 0

运行时使用：

DSurfTomo_lst.in
surfdataTB.dat
MOD

MOD.true 不参与实际数据反演。

9.2 合成测试

synthetic flag = 1

运行时使用：

DSurfTomo_lst.in
surfdataTB.dat
MOD

MOD 为反演初始模型，MOD.true 为真实模型。程序根据 surfdataTB.dat 中的台站分布、台站对关系、周期和数据类型，利用 MOD.true 计算合成数据，再从 MOD 开始反演。

10. 输出文件

10.1 日志文件

若参数文件名为 DSurfTomo_lst.in，日志文件为：

DSurfTomo_lst.in.log

日志中记录模型参数、周期、LST 参数、各次迭代的残差信息、速度扰动和主要运行信息。

10.2 每次迭代的速度模型

DSurfTomo_lst.inMeasure.dat.iter001
DSurfTomo_lst.inMeasure.dat.iter002
...
DSurfTomo_lst.inMeasure.dat.iter010

每行格式为：

longitude latitude depth Vs

其中经纬度单位为度，深度单位为 km，Vs 单位为 km/s。

10.3 实际数据最终模型

当 synthetic flag=0 时，最终模型写入：

DSurfTomo_lst.inMeasure.dat

数据格式与迭代模型相同。

10.4 合成测试输出

当 synthetic flag=1 时，程序输出：

Vs_model.real
DSurfTomo_lst.inSyn.dat

Vs_model.real 为真实模型，DSurfTomo_lst.inSyn.dat 为最终反演模型。两者均采用： 

longitude latitude depth Vs

10.5 残差文件

residualFirst.dat
residualLast.dat

分别保存第一次和最后一次外循环的数据拟合结果。每行包含六列：

Distance ForwardT ObserveT weightedForwardT weightedObserveT weight

10.6 DWS

norm_dws.dat

该文件保存最后一次外循环计算得到的 DWS（Derivative Weight Sum）。每行格式为： 

longitude latitude depth DWS

第四列为对应模型参数的数据灵敏度矩阵列绝对值之和。

10.7 字典文件

程序结束后输出字典元数据，以及各反演深度层的初始字典和最终字典：

DSurfTomo_lst.in.dict_metadata.txt

DSurfTomo_lst.in.dict_initial_layer001.txt
...
DSurfTomo_lst.in.dict_final_layer001.txt
...

初始字典为程序初始化的 DCT 字典，最终字典为反演结束时保存的字典。每个字典文件的矩阵大小为 nib² × K_dict，每一列对应一个字典原子。

示例中 nib=4、K_dict=16，因此每个字典文件为 16 行 × 16 列。参与字典正则化的深度层数为 nz-1。

11. 模型输出范围

输入模型网格为 nx × ny × nz，实际参与反演并写入速度结果的节点数为：

(nx - 2) × (ny - 2) × (nz - 1)

对于示例模型：

nx = 18
ny = 18
nz = 9

输出节点数 = 16 × 16 × 8 = 2048

水平方向最外侧一圈节点不作为独立反演参数，最深的第 nz 个深度节点也不作为独立反演层。因此后处理、绘图和合成测试误差计算应使用实际输出的节点范围。

12. 常见问题

12.1 unable to open the inputfile

STOP unable to open the inputfile

程序未找到指定的参数文件。检查参数文件名、文件所在目录和启动命令。

12.2 MOD 或 MOD.true 无法读取

检查文件名及格式是否正确。Windows 若隐藏已知文件类型的扩展名，实际文件可能被保存为 MOD.txt 或 MOD.true.txt。

12.3 increase sparsity fraction(spfra)

increase sparsity fraction(spfra)

表示为稀疏灵敏度矩阵预分配的空间不足，应增大 DSurfTomo_lst.in 中的 sparsity fraction。该参数只控制存储空间，与 T_sparse 无关。

12.4 LST 参数检查

程序启动时检查以下条件：

nx > 2
ny > 2
nz > 1
Minvel < Maxvel
nib >= 1
K_dict >= 1
1 <= T_sparse <= K_dict
lam2_dict > 0
lam_z_dict >= 0
warmup_iters >= 0
dict_freq >= 1

13. 参数取值

DSurfTomo-LST 论文中的参数敏感性分析给出了下列经验范围。不同数据集可通过 checkerboard、spike 等合成试验确定最终参数。

参数经验范围或取值方式
nib 论文中建议 patch 边长约为较短一侧水平模型网格数的 1/10。本示例取 4。
K_dict 通常取 nib² 至约 1.5×nib²。
T_sparse 通常取 2–4。
warmup_iters 通常取 1–5，并与总外循环次数配合设置。
dict_freq 通常每 2–3 次外循环更新一次字典。
lam1_dict 通过合成试验或参数扫描确定。
lam2_dict 通过合成试验或参数扫描确定。
lam_z_dict 通过合成试验或参数扫描确定。
